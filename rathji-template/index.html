🪄 rathji-template

A self-contained template by Rathji: a pretty colored badge (text + emoji + accent color) you call straight from a list or script. No $output, no import machinery — just copy the code into any generator and it works.

What this is

rathjiTemplate() is just a function in this generator's main.pjs that renders a badge on its own page, and every piece of code you need is yours to copy. Call it directly, tweak it freely, no import line required.

This page doubles as docs and a live test harness — every claim below is exercised by the demo at the bottom.

How it's structured

main.pjs is organised into three sections:

SectionWhat it's for
$metaTitle, description and tags — shown on your listing page
Lists — rathjiTemplateOpts, rathjiTemplatePresets (+ rathjiCardOpts, rathjiCardPresets)Reusable options values; pass them straight to the component functions
Helpers — rathjiTemplateResolve(), rathjiTemplateStamp(), rathjiCardStamp()The real logic, kept out of the entry points so they stay thin and testable
rathjiTemplate() / rathjiCard()The two entry points — call these from lists or scripts

Notes

  • The component never throws — bad input returns (rathjiTemplate: expected some text — …) instead of an exception.
  • Arguments support plain values and Perchance lists alike (every pjs value is a node, read through evaluateItem).
  • The Random preset case proves passing a whole list of option-nodes works — rathjiTemplate() picks one at random.
  • Press R or Space anywhere on the page to reroll a random preset badge (ignored while typing or with a modal open).
  • Settings accept URL overrides: ?theme=light&accent=%23ec4899&size=18&motion=true.
  • Two components ship with this template — badges and cards — with the same API shape, so learning one teaches you the other.
  • More generators by Rathji: perchance.org/rathjis-generators
